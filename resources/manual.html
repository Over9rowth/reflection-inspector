反光检查镜

用户使用说明书 · 适用于 0.2.0 及以后版本
一句话说明：它帮你在照片里找出「镜子、玻璃、屏幕、金属」这类会反光的区域， 由你确认后盖上纯色块或马赛克，再按原图尺寸导出。模型只提建议，盖不盖由你决定。

1. 它适合谁

  • 发二手物品照片，不想让镜子照出家中的布局；
  • 发工作照，不想让屏幕上的聊天记录被拍进去；
  • 发旅拍，不想让玻璃反光里出现同行的人。

2. 三步上手

第一步：打开照片

点左上角「选择照片」，或直接把图片文件拖进窗口。支持 JPEG、PNG、WebP。

第二步：找出反光

有两条路，选一条就行：

  • 自动建议（需要模型资源，见第 4 节）：点顶栏「自动建议」，稍等十几秒， 右侧会出现若干条候选区域，每条都标了类型（镜子 / 玻璃）和置信度。
  • 手动框选（任何时候都能用）：点顶栏「手动框选」，在照片上按住拖一个框， 松手就生成一条遮挡区域。

自动建议出来后，逐条点「接受」或「拒绝」。只有被接受的那条才会被盖住。

第三步：检查并导出

  1. 用鼠标滚轮放大，拖动画面平移，仔细看反光里到底有什么——这一步别省。
  2. 确认每条遮挡是「纯色块」还是「马赛克」；纯色块更彻底，马赛克保留一点画面结构。
  3. 点「导出遮挡图」，选保存位置。导出的图片是原图尺寸，且不含 EXIF （拍摄地点、机型、时间都去掉了）。
重要：导出的是新文件，原图不会被改动。如果原图已经发出去过，这次的遮挡不能收回之前的。

3. 它不能做什么

场景实际表现
暗光、过曝的强反光可能漏检，请手动补框
曲面镜、球面金属建议框可能不准，建议手动框选
画面里很小的一块反光可能漏检，请放大后手动补
判断「这块是不是反光」模型只给候选，最终要靠你自己看
RAW / HEIC 格式不支持，请先转成 JPEG 或 PNG
它不是测量仪器，也不是取证工具。遮挡是像素替换，不做加密、不做不可逆销毁； 它也不做人脸或文字识别，只告诉你「这里是一块反光面」。

4. 运行环境与模型资源

安装包不含模型权重（约 1 GB），这样安装包才不至于大到没法下载。首次打开如果发现资源不齐， 会自动弹出「运行环境与模型资源」向导。

4.1 一键下载并校验

  • 只有你点了「一键下载并校验模型资源」，程序才会联网；
  • 每个文件都按清单里固定的版本号与 SHA-256 校验，先存成 .part，校验通过才改名；
  • 校验不通过的文件会被删掉，不会留下坏文件；
  • 默认存到 %LOCALAPPDATA%\Over9rowth\ReflectionInspector\models。

4.2 导入本地离线资源包

如果已经有别人给你的模型目录（里面应当包含 grounding-dino-tiny 与 sam-vit-base 两个子目录），点「导入本地离线资源包」选中那个目录即可。程序只校验与登记，不会复制文件。

4.3 不想装？用纯手动模式

在向导里点「稍后再说（用纯手动模式）」，向导会关掉，之后：

  • 「自动建议」按钮不可用（灰色）；
  • 手动框选、纯色块、马赛克、全分辨率导出，全部照常可用；
  • 顶栏会显示「纯手动模式」，随时点它可以重新打开向导。

5. 常见问题

现象怎么办
点「自动建议」没反应 / 按钮是灰的看顶栏是否显示「纯手动模式」。是的话点它打开向导，补齐资源后再试。
下载到一半失败再点一次「一键下载并校验」即可，已校验通过的文件会跳过。
导出的图比原图小正常不会。若发生，请确认没有在导出对话框里选到缩放选项，并反馈该现象。
卸载后资源目录还在模型资源放在用户目录，卸载不删除，避免重装后又要下 1 GB。可手动删 %LOCALAPPDATA%\Over9rowth\ReflectionInspector。
Windows 提示「未知发布者」安装包未做代码签名，属正常现象，选择「更多信息 → 仍要运行」。

6. 隐私说明

  • 照片只在本机内存与本地磁盘处理，没有任何上传接口；
  • 推理在本机 Python 进程里进行，强制离线模式；
  • 只有「一键下载模型资源」会在你确认后访问 Hugging Face 官方地址，且只下载模型文件，不上传任何内容。
